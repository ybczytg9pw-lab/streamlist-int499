# Week 1 ScreenPal presentation script — about 3 minutes

**Before recording:** Open the running app in Chrome or Edge. Press F12 and select the Console tab. Have Visual Studio Code open to the project, ideally showing `App.jsx` and `StreamListForm.jsx`. Record your actual screen and your own explanation.

**0:00–0:25 — Introduction and purpose**

"Hello, my name is Bryant Malone, and this is my Week 1 project for INT499, IT Capstone. For this assignment, I created a React application called StreamList for EZTechMovie. The idea behind StreamList is to give users one place to track movies and TV shows they want to watch. This week's focus is building the foundation for the features we'll add in the coming weeks."

**0:25–1:10 — Navigation walkthrough**

"I started with React and used React Router to set up navigation. Across the top, I have four menu choices: StreamList, Movies, Cart, and About. StreamList is the homepage. When I click Movies, it takes me to a separate Movies component. The Cart and About links work the same way. I purposely left those pages without actual data because the instructions say those sections will be built in Weeks 4 and 5. You can see that the menu changes pages without refreshing the whole website."

**1:10–2:05 — Form and developer console**

"Now I'm back on the StreamList homepage. This form lets someone type in the name of a movie or show. I separated the form into its own React component so I can reuse it later. The form uses state to keep track of what's typed in, and when I click Add title, it sends the title back to the homepage through a prop called onSubmitTitle. Right now, the homepage logs it to the browser console. Let me enter The Pursuit of Happyness, click Add title, and show that the text appears here in the console. The screen also lets the user know the input was sent."

**2:05–2:45 — Design and coding process**

"I also customized the appearance using CSS, including the dark movie-themed colors, buttons, spacing, and responsive layout. I added free Google Material Symbols icons to help identify the menu choices. In Visual Studio Code, I kept the project organized with separate folders for components and pages. That is something I learned was helpful in my INT304 Web Design and Development class, especially when an app starts to grow."

**2:45–3:10 — Wrap-up**

"One important lesson from this first week is that navigation and input handling need to work before I add more complicated features. Next, I'll build on this structure to handle list data and eventually the Movies, Cart, and About sections. I've also included my GitHub repository link so the code can be reviewed. Thank you for watching."

**Recording checklist**

- Speak naturally rather than reading every word.
- Make the Chrome/Edge Console readable before demonstrating the input.
- Click all four navigation links on camera.
- Show at least one successful input submission.
- Show the project folders and source code in Visual Studio Code.
- Keep the final video between 2 and 5 minutes.
- Upload the **actual video file** through the Canvas assignment, and provide the GitHub URL where requested.
